# projects

Minimal Java 21 project scaffold using Gradle with Kotlin DSL.

## Requirements

- Java 21

## Project Layout

```text
.
├── build.gradle.kts
├── gradle/
├── gradlew
├── gradlew.bat
├── settings.gradle.kts
└── src
    ├── main/java/com/example/projects
    └── test/java/com/example/projects
```

## Commands

```bash
./gradlew run
./gradlew test
./gradlew build
```

The sample application prints a greeting and includes a small test suite so the project is ready to build and extend.
